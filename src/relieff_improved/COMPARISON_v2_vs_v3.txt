• Fallbacks: mayor robustez en producción

• Warmup: convergencia más estable (evita oscilaciones iniciales)
• L2 reg: previene overfitting de prototipos
• Class weighting: mejor rendimiento en datasets desbalanceados
• Checkpointing: garantiza mejores prototipos finales

5. MEJORAS IMPLEMENTADAS (RESUMEN)
───────────────────────────────────────────────────────────────────────────────

AMBAS VERSIONES v3:
• Validación exhaustiva de parámetros
• Type hints completos (Python 3.10+)
• Logging estructurado con niveles
• Documentación docstring detallada
• Métricas internas para análisis
• API get_metrics() para inspección
• Manejo robusto de errores

ESPECÍFICAS ANN v3:
• _compute_scores_numba_batched(): procesa por bloques (cache-friendly)
• _validate_params(): detecta configs inválidas antes de fit
• _get_adaptive_params(): 6 niveles de adaptación (era 4)
• Fallback automático HNSW → sklearn si falla
• Scaler configurable (MinMax/Standard/None)

ESPECÍFICAS Proto v3:
• _get_lr_schedule(): warmup + 3 tipos de decay
• _refine_prototypes_lvq_advanced(): early stop + L2 reg + checkpointing
• _compute_adaptive_softmax_weights(): 3 estrategias de temperatura
• _generate_validated_prototypes(): métricas de calidad por cluster
• Soporte class_weight para desbalance
• get_prototypes(): acceso a prototipos finales

9. CÓDIGO EJEMPLO DE USO
───────────────────────────────────────────────────────────────────────────────

```python
# ANN v3 - Configuración rápida
from ann_v3 import ANN_v3

ann = ANN_v3(
    n_neighbors=10,
    n_features_to_select=20,
    iter_ratio='auto',      # Adaptativo
    metric='euclidean',
    verbose=True
)
ann.fit(X_train, y_train)
X_selected = ann.transform(X_test)

# Ver métricas
metrics = ann.get_metrics()
print(f"Build time: {metrics['build_time']:.2f}s")
print(f"Used HNSW: {metrics['used_hnsw']}")


# Proto v3 - Configuración avanzada
from proto_v3 import Proto_v3

proto = Proto_v3(
    n_features_to_select=20,
    sigma=0.05,
    use_lvq=True,
    lvq_epochs=10,
    lvq_lr=0.1,
    lvq_lr_decay='cosine',     # Cosine decay
    lvq_early_stopping=True,
    gamma='adaptive',           # Softmax adaptativo
    gamma_strategy='variance',
    class_weight='balanced',    # Para desbalance
    verbose=True,
    enable_logging=True
)
proto.fit(X_train, y_train)
X_selected = proto.transform(X_test)

# Análisis de prototipos
prototypes = proto.get_prototypes()
for c, protos in prototypes.items():
    print(f"Class {c}: {len(protos)} prototypes")

# Visualizar convergencia LVQ
metrics = proto.get_metrics()
import matplotlib.pyplot as plt
plt.plot(metrics['lvq_convergence'])
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.title('LVQ Convergence')
plt.show()
```
